# Assignment Submission Tracker 📚📊

An interactive **Assignment Submission Tracker** built using **Microsoft Excel** to monitor and manage student assignment submissions.

### 📌 Project Features
- Student-wise assignment tracking
- Submission status tracking
- Identifies **Submitted, Late Submitted, and Not Submitted** assignments
- Dashboard for visualizing submission status
- Interactive filtering using slicers
- Feedback tracking
- Clear Feedback functionality using an Excel macro
- Protected cells for controlled data entry

### 🛠️ Tools Used
- Microsoft Excel
- Excel Dashboard
- Pivot Tables
- Slicers
- Excel Macros (VBA)

### 🎯 Objective
The objective of this project is to create an organized assignment tracking system that makes it easier to monitor student submissions, identify late or missing assignments, and analyze submission status through an interactive dashboard.
